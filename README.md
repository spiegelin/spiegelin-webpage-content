# Contributions Welcome

This repository contains the content for [my personal webpage](https://spiegelin.com). If you find any mistakes, typos, grammatical errors, or have suggestions to improve the content, I'd love to have your help!

## What Can You Fix?

Contributions are welcome for:
- **Grammar and spelling errors** - Typos, grammatical mistakes, or awkward phrasing
- **Clarity improvements** - Making content clearer or easier to understand
- **Technical corrections** - Incorrect information or outdated details
- **Formatting issues** - Markdown formatting problems
- **Broken links** - Dead or incorrect links that need fixing

## How to Contribute

1. **Fork this repository**
2. **Make your changes** - Edit the relevant `.mdx` file(s) in the appropriate directory.
3. **Test your changes** - Make sure the Markdown/MDX syntax is correct
4. **Create a pull request** - Describe what you fixed and why

## Questions?

If you're unsure about a change or want to discuss something before submitting, feel free to open an issue instead of a pull request.

Thank you for helping improve the content!
